## Описание проекта

«Арканоид» — двумерная аркадная игра, в которой игрок перемещает ракетку горизонтально и отбивает шарик, разрушая кирпичи. Цель игры — очистить поле, сохранив жизни.

На текущем этапе открывается окно 480 × 640 пикселей с игровым полем, ракеткой, одним шариком и 30 одинаковыми кирпичами. Счётчики показывают ноль очков и три жизни. Движение, управление и правила игры будут добавлены на следующих этапах.

## Функциональные возможности

- Управление ракеткой мышью или стрелками влево и вправо.
- Один шарик на игровом поле и ракетка постоянного размера.
- Отскоки шарика от боковых стен, верхней границы и ракетки.
- Одинаковые кирпичи, каждый из которых разрушается от одного попадания.
- Одно очко за разрушенный кирпич.
- Три жизни в начале партии. Падение шарика за нижнюю границу отнимает жизнь.
- Подготовка нового запуска шарика после потери жизни.
- Победа после разрушения всех кирпичей и проигрыш после потери последней жизни.
- Пауза, повторный запуск партии и выход через меню.

## Требования к системе

- Python 3.11.
- Pygame 2.6.1.
- Windows, macOS или Linux с графической средой.
- Git для клонирования репозитория.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/mihailfomin7815-debug/3.3-.git
cd 3.3-
```

Если проект уже находится на компьютере, откройте терминал в его папке.

### 2. Создание и активация виртуального окружения

**Windows (PowerShell)**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS и Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

Папка `venv/` входит в структуру проекта согласно требованиям преподавателя. На другом компьютере окружение создаётся заново командами выше.

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск программы

Откройте терминал в корне проекта и выполните команду запуска.

```bash
python main.py
```

### 5. Управление

На текущем этапе окно закрывается стандартной кнопкой закрытия. Ниже приведено запланированное управление готовой игрой.

| Действие | Управление |
| --- | --- |
| Перемещение ракетки | Мышь или стрелки влево/вправо |
| Запуск шарика | Пробел или левая кнопка мыши |
| Новая партия | R |
| Меню паузы | Esc |

## Структура проекта

```text
.
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── src/
│   ├── app.py
│   ├── model.py
│   └── renderer.py
├── tests/
│   └── .gitkeep
└── venv/
```

- `main.py` — точка входа.
- `src/app.py` — создание окна, обработка событий и главный цикл.
- `src/model.py` — параметры, состояние ракетки, шарика и кирпичей, расчёт движения и столкновений, очки и жизни.
- `src/renderer.py` — отрисовка поля, игровых объектов, счётчиков и меню.
- `tests/` — будущие автоматические проверки. Файл `.gitkeep` позволяет сохранить пустую папку в Git.
- `venv/` — виртуальное окружение Python с зависимостями из `requirements.txt`.

Четыре исходных файла разделяют запуск, обработку ввода, правила игры и отрисовку. Такое разделение позволяет тестировать расчёты и правила независимо от окна. Параметры игрового поля собраны в начале `src/model.py` и снабжены комментариями с единицами измерения.

## Пример использования

После запуска готовой игры переместите ракетку мышью или стрелками и нажмите пробел для запуска шарика. Подставляйте ракетку под падающий шарик и наблюдайте за разрушением кирпичей и изменением счёта. При потере шарика запустите следующий, пока остаются жизни.

## Тестирование

На заключительном этапе проверки на встроенном `unittest` охватят движение и границы ракетки, отскоки шарика, разрушение кирпичей, очки, жизни, победу, проигрыш и перезапуск. Команда запуска из корня проекта в активированном окружении приведена ниже.

```bash
python -m unittest discover -s tests -v
```
